# 旁听 Sidenote 隐私政策与数据权限说明

更新日期：2026 年 9 月 14 日。

本政策适用于「旁听 Sidenote - YouTube AI 学习助手」浏览器扩展及其服务端。有关本政策、账号数据访问或删除的请求，可通过项目支持页面联系开发者：https://github.com/muqinglang/youtube-summary/issues 。请勿在公开 Issue 中提交密码、API Key、登录令牌或其他敏感内容。

使用扩展需要先用 Google 账号登录。AI 功能有两种运行方式，字幕去向不同，请按你实际使用的那种阅读；目前开放的是自带 Key。

|             | **自带 Key**（默认）       | **托管**（暂未开放）                             |
| ----------- | -------------------------- | ------------------------------------------------ |
| AI 请求发往 | 你自己配置的服务商         | 旁听服务端，再由它转发给服务商                   |
| 字幕去向    | 只发给你的服务商           | **上传到旁听服务端并保存**                       |
| 结果保存    | 本机缓存，并保存到你的账号 | 同左；另外服务端按视频保存一份，并与其他用户共享 |

无论哪种方式，「默认字幕」翻译都会把字幕发往 Google 的公共翻译接口（见下）。扩展没有统计 SDK，不使用浏览器同步存储。

## 账号与云端保存

登录只向 Google 申请 `openid email`，读取账号标识与邮箱地址，不读取你的 Google 其他数据。旁听服务端保存这两项，不保存任何密码。

登录后，以下内容保存在旁听服务端，按账号隔离，只有你的账号能读取，不与其他用户共享：

- 你存下的笔记：句子、时间点、译文和你写下的想法；
- 你生成的 AI 结果：总结、内容目录、引导问题、术语表、划词解释和问答回答。

保存它们是为了让你换电脑、重装扩展或清除本机缓存后，打开同一个视频还能看到。条目按视频编号或内容摘要值命名，服务端因此知道你为哪些视频保存过笔记。每个账号最多保存约 20 MB。字幕译文、自定义 Prompt、偏好设置和 API Key 不会上传。

退出登录只清除本机登录令牌，不删除账号里保存的内容。在同一台电脑上换另一个 Google 账号登录时，本机上属于上一个账号的笔记和结果副本会被清除，它们仍保存在上一个账号里。

## 本机保存的数据

| 数据                       | 使用与保存                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 视频标题、链接、作者、字幕 | 从当前 YouTube 视频读取；发起 AI 操作后，所需内容会按上表发送                                                        |
| Prompt、提问、目标语言     | 用于用户主动发起的总结、翻译或问答；Prompt 与偏好在本机保存                                                          |
| API Key                    | 仅后台用于请求授权。默认记住在本机扩展存储；取消勾选后只放在浏览器会话存储，浏览器关闭即清除。可在设置清除           |
| 登录令牌                   | 保存在本机扩展存储，与签发它的服务地址绑定；退出登录即清除。面板永远拿不到它，只能看到「是否已登录」                 |
| 笔记                       | 保存在本机扩展存储，并同步到你的账号（见上）                                                                         |
| AI 结果                    | 在本机有界缓存中保存（最多 20 条、约 4 MB、30 天），可在设置清除；同时保存到你的账号，清除本机缓存不影响账号里的副本 |
| 学习会话与原字幕           | 在浏览器会话存储保留最多十个学习会话及对应字幕，用于复用学习标签；会话结束清除                                       |
| 打印页内容                 | 临时放在会话存储供排版页读取，最多保留最近五份；浏览器会话结束后清除                                                 |
| 导出文件                   | PDF / XMind / Markdown 全部在本机生成，直接存到浏览器下载位置，不经过任何服务器                                      |

本机记住的密钥使用浏览器扩展存储，不是操作系统密码保险库，也未额外加密。用户所配置服务对收到数据的保留方式由该服务决定。

## 字幕翻译

默认的「默认字幕」把字幕**逐条发送到 Google 的公共网页翻译接口** `translate.googleapis.com/translate_a/single`，翻译后返回，免 Key、免下载语言包。该接口是 Google 未公开文档的内部端点，可能随时变更或限流。译文写入本机缓存。

选择「AI 字幕」则改用你配置的模型（自带 Key 模式）或旁听服务端（托管模式）。两者不会在失败后互相自动切换，失败时显示错误。关闭学习页或取消任务会中止进行中的翻译。

「用 Google 网页翻译当前句」入口仅在用户主动点击时，把当前一句和目标语言放进 Google 翻译网页链接；不上传整片字幕，也不自动回填译文。

## 托管模式额外说明

托管模式目前没有开放。开放后，只有在设置里主动切换到托管模式，以下才会发生：

- **字幕会上传到旁听服务端**，用于生成总结、目录、引导问题和问答，并按视频保存。
- **生成结果按视频缓存，并对所有用户共享**。同一个视频别人处理过，你会直接读到那份结果，你的结果也会被别人读到。这些内容不含任何账号信息。
- **跨视频检索会把字幕切片发送给向量服务**：运营方配置的 embedding 服务商（当前为阿里云百炼）把切片转成向量，向量存在服务端，只用于在你自己看过的视频里检索。
- 服务端保存：Google 账号标识与邮箱（**不保存任何密码**）、你打开过的视频列表、每日任务计数，以及已处理视频的字幕切片与向量。登录令牌由服务端签发、只保存在本机。
- 服务端**不会**收到你的 API Key —— 托管模式用的是运营方自己的密钥。

自带 Key 模式同样会把执行 AI 功能所需的字幕和问题发送给所选 AI 服务商。若不希望字幕文本发送给翻译或 AI 服务，请关闭自动翻译，并不要发起 AI 翻译、总结、目录、引导提问、问答或托管处理。YouTube 视频播放和原始字幕读取仍需要与 YouTube 通信。

## 数据用途与用户控制

处理的数据还包括用户主动输入的 AI 问题、自定义提示词，以及为播放同步、学习会话恢复和托管额度管理所需的播放位置与任务使用情况。这些信息用于用户请求的视频学习功能，不用于广告画像。

用户可在设置中清除保存的 API Key 和本机学习缓存；退出登录会清除本机登录令牌。退出登录、清除本机存储或卸载扩展，都不会删除服务端的账号，以及账号里保存的笔记、AI 结果和资料库。这些数据目前没有自动到期删除期限；如需访问、导出或删除你的账号及其保存的内容，请通过上述支持入口联系开发者。各第三方服务接收数据后的保存与处理规则由其各自政策决定。

旁听 Sidenote 对通过 Chrome 扩展取得的用户数据的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。用户数据仅用于提供或改进上述视频学习功能；不会出售用户数据，不会将其用于个性化广告、信用评估或贷款决策，不会为了与单一用途无关的目的使用或转移数据。数据仅在提供这些功能所必需的范围内传输给相应服务商，或在适用法律、安全要求等政策允许的情形下披露。

## 权限用途

- `storage`：偏好、密钥、登录令牌、笔记、学习缓存和临时排版文档。
- `activeTab`：用户点击工具栏后识别当前视频并打开独立学习页。
- `identity`：用于 Google 登录，只申请 `openid email`，读取 Google 账号标识与邮箱地址。
- YouTube 站点权限：读取字幕轨、播放器状态和转录内容，注入点赞旁的入口。必要时展开原视频描述中的「显示转录内容」。
- `translate.googleapis.com` 站点权限：「默认字幕」向该域发送字幕文本并接收译文；仅用于翻译。
- `webRequest`：只查看浏览器发往 YouTube 字幕接口（`/api/timedtext`）的请求地址。YouTube 多数自动字幕只对它自己的播放器开放，扩展因此用播放器已经请求过的地址再读取一次这份字幕。不拦截、不修改请求，也不查看其他网站的请求。
- `declarativeNetRequestWithHostAccess`：只对本扩展发起的 YouTube 嵌入框架请求设置客户端 Referer，其中包含本扩展真实 ID，用于 YouTube 识别播放器客户端；不会修改其他网页或扩展的请求。
- 可选站点权限：仅限三家 AI 服务商的官方域名与旁听服务域名。服务商域名在保存对应配置时申请，旁听服务域名在登录时申请。清单中不含通配的 HTTPS 范围，安装时不会授权任意站点。

关闭学习页会取消进行中的 AI 请求。已经到达 AI 服务的请求是否产生费用，由服务的计费规则决定。连接测试也会发送一条简短请求。扩展不会上传导出文件，不会下载视频或绕过访问限制。
