# 数据与权限说明

当前版本没有运营方服务器、登录、统计 SDK 或云同步。

| 数据                       | 使用与保存                                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 视频标题、链接、作者、字幕 | 从当前 YouTube 视频读取；点击 AI 操作后，所需内容会发给用户设置的 AI 服务                                      |
| Prompt、提问、目标语言     | 用于用户主动发起的总结、翻译或问答；Prompt 与偏好在本机保存                                                    |
| API Key                    | 仅后台用于请求授权。默认放在浏览器会话存储；选择记住后放在本机扩展存储，可在设置清除                           |
| AI 结果                    | 在本机有界缓存中保存，可在设置清除缓存；导出文件存到浏览器下载位置                                             |
| Google 云端翻译（默认字幕）| 「默认字幕」把字幕逐条发送到 Google 公共翻译接口 `translate.googleapis.com` 翻译并返回，免 Key、免下载语言包；译文写入本机有界缓存 |
| Google 翻译网页入口        | 用户主动点击时，只把当前句和目标语言放入 Google 翻译网页链接；不上传整片字幕、不自动回填译文                   |
| 学习会话与原字幕           | 在浏览器会话存储保留最多十个学习会话及对应字幕，用于复用学习标签；会话结束清除                                 |
| PDF 导出内容               | 临时放在会话存储供打印页读取，最多保留最近五份导出；浏览器会话结束后清除                                       |

本机记住的密钥使用浏览器扩展存储，不是操作系统密码保险库，也未额外加密。不使用浏览器同步存储。用户所配置服务对收到数据的保留方式由该服务决定。

默认使用「默认字幕」= Google 云端翻译（`translate.googleapis.com`），免 Key、免下载语言包、即时；字幕文本会发送到 Google（与 Trancy 等工具相同）。用户点「AI 字幕」才改用自己配置的 AI 模型。两者都不会在失败后互相自动切换，失败时显示错误。关闭学习页或取消任务会中止进行中的翻译。

权限用途：

- `storage`：偏好、密钥、学习缓存和临时打印文档。
- `activeTab`：用户点击工具栏后识别当前视频并打开独立学习页。
- YouTube 站点权限：读取字幕轨、播放器状态和转录内容，注入点赞旁的入口。必要时展开原视频描述中的「显示转录内容」。
- `translate.googleapis.com` 站点权限：「默认字幕」用 Google 云端翻译时向该域发送字幕文本并接收译文；仅用于翻译。
- `declarativeNetRequestWithHostAccess`：只对本扩展发起的 YouTube 嵌入框架请求设置客户端 Referer，其中包含本扩展真实 ID，用于 YouTube 识别播放器客户端；不会修改其他网页或扩展的请求。
- 可选 API 站点权限：用户保存所选服务商时，只请求其固定官方来源域的访问权限；旧配置与本机测试仍支持原有端点。清单中的可选 HTTPS 范围不会在安装时自动授权所有站点。

关闭学习页会取消进行中的 AI 请求。已经到达 AI 服务的请求是否产生费用，由服务的计费规则决定。连接测试也会发送一条简短请求。扩展不会上传导出文件，不会下载视频或绕过访问限制。
