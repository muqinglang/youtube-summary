# 旁听 Sidenote 支持

旁听 Sidenote 是用于学习和复习 YouTube 视频的 Chrome 扩展。

## 联系与反馈

遇到登录、字幕、AI、笔记同步或导出问题，请到 [GitHub Issues](https://github.com/muqinglang/youtube-summary/issues) 提交反馈，或发送邮件至 langli0728@gmail.com。

请说明扩展版本、Chrome 版本、操作步骤和错误提示。请勿公开提交 API Key、密码、登录令牌或其他敏感信息。

账号数据访问、导出和删除请求也可通过上述邮箱联系开发者。

## 0.8.0 使用说明

1. 打开有字幕的 YouTube 视频，点击「旁听 AI」，使用 Google 账号登录。
2. 登录后，默认双语字幕无需 API Key。
3. AI 功能需要在设置中选择 OpenAI、DeepSeek 或 Claude，并填写自己的有效 API Key；相关调用费用由服务商收取。
4. 笔记与 AI 结果按账号同步。重装或换设备后，打开同一视频恢复笔记；AI 结果需选择相同服务商和模型，再点击生成读取保存结果。

详见 [隐私政策](privacy.md)。
