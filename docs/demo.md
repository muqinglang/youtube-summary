# 旁听 Sidenote · YouTube 学习插件 UI Demo

## 打开预览

直接双击 **sidenote-demo.html**。这是单个离线 HTML 文件，包含样式、脚本、图标和示例画面，不需要安装依赖或配置 API。

也可以打开 `index.html`（需要保留同目录的 `styles.css`、`app.js`、`panel.css`、`panel.js` 和 `assets`）。可选本地服务：运行 `node preview-server.cjs`，访问 http://127.0.0.1:4173。

## 建议验证顺序

1. 点击右上角 **功能引导**，浏览六个步骤。
2. 播放演示、拖动进度，或点击章节和字幕，检查时间同步。
3. 切换翻译语言、原文/译文显示模式。字幕面板可搜索，手动滚动可暂停跟随。
4. 切换 **AI 总结**，打开 **自定义 Prompt**，编辑、保存或切换模板。
5. 打开 **思维导图**，展开/收起节点；从 **导出笔记** 体验导出入口。
6. 打开 **AI 问答**，输入问题，再点击演示回答中的时间点回看。
7. 在页面底部 **查看验证清单** 勾选已确认部分，填写修改建议，可下载反馈文本。

## 已实现的演示交互

- 参考截图风格的深色学习工作台，桌面双栏、窄屏上下排列，影院/全屏入口。
- 静态参考画面和可控制的模拟时间轴；播放、暂停、前后十秒、速度和章节切换。
- 原创示例字幕，含中文、日语、西班牙语、法语译文以及英语显示。
- 字幕高亮、自动滚动、字幕搜索与空状态、点击跳转、显示模式和字号调整。
- 演示总结及生成中状态、自定义 Prompt 三个模板与本地保存。
- 树状思维导图、节点折叠、预设问答和时间戳。
- PDF：打开浏览器打印窗口，选择“另存为 PDF”；Markdown：实际下载示例笔记；XMind：展示布局和时间戳设置预览。
- 六步高亮引导、偏好设置、收藏状态、学习进度记忆、可下载的验证反馈。

## 本次范围

这是一份供用户确认设计的交互原型，不是已开发完成的浏览器扩展。

视频画面来自用户提供的截图，**不会播放真实视频，也没有音频**。18:42 的时间轴、字幕、总结和问答都是原创演示数据，不代表截图中原视频的真实内容。AI 问答为预设答案，自定义 Prompt 仅保存，不会影响当前示例总结。没有调用任何模型或 YouTube 接口。XMind 尚不生成真实 `.xmind` 文件。

提示词、偏好、进度和反馈只保存在当前浏览器本地；不会自动发送。确认 UI 后，再开发真实字幕获取、AI 翻译/总结/问答、长视频处理和 XMind 导出。

## 调整与打包

修改 `index.html`、`styles.css`、`app.js`、`panel.js`、`panel.css` 后运行 `node build-demo.cjs`，即可重新生成单文件 `sidenote-demo.html`。

图标来自 Tabler Icons，MIT 许可见 `assets/icons/LICENSE`。整个 Demo 的运行不依赖外部网络、第三方 CDN 或构建工具。
