# 旁听 Sidenote · YouTube AI 学习插件

Chrome / Edge Manifest V3 扩展，把 YouTube 视频变成可检索、可复习的学习笔记。当前版本 `0.6.0`。

打开独立学习页：左侧是视频与双语字幕，右侧按「字幕｜章节｜引导提问｜AI 总结｜AI 问答」切换。双语字幕默认免 Key 直接可用；AI 总结、内容目录和问答使用你自己的 OpenAI、DeepSeek 或 Claude API Key。

> 尚未上架浏览器商店，需要手动加载。也没有登录、订阅和云端同步：所有数据留在本机。

## 安装（普通用户）

1. 在 [Releases](../../releases) 下载 `sidenote-0.6.0.zip` 并解压。
2. 用 Chrome / Edge 130 或更新版本打开 `chrome://extensions` / `edge://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」，选择解压后**包含 `manifest.json` 的那一层文件夹**。

两点需要提前知道：

- 以开发者模式加载的扩展，每次启动浏览器都会弹一次「请停用以开发者模式运行的扩展程序」提示，关掉即可，无法消除。这是浏览器对非商店扩展的统一行为。
- 更新需要重新下载并再次加载，没有自动更新。

## 开始使用

1. 打开或刷新 YouTube 视频页，点击视频下方点赞左侧的 **旁听 AI** 按钮，或工具栏中的旁听图标。扩展会暂停原视频并打开独立学习标签；同一视频再次点击会回到已有标签。
2. 等待字幕读取完成，期间请保留原 YouTube 标签页。扩展必要时会打开原视频的「显示转录内容」读取字幕，也可以导入该视频对应的 SRT / VTT 文件。
3. 选择目标语言即可，字幕载入后会**随播放自动逐句翻译**，无需手动点按钮。视频下方与右侧字幕列表同步显示双语，当前句高亮跟随。
4. 需要 AI 总结或问答时，在顶部「AI 设置」选择 **服务商 → 模型**，再填写对应 **API Key**。服务地址由扩展内置，保存并允许访问后即可测试连接。切换服务商会清除旧密钥。默认不记住密钥，浏览器关闭即清除；勾选记住后存于本机。
5. 使用「导出笔记」下载 **PDF** / XMind / Markdown，都是一键直接下载。菜单里的「打印」会另开排版页调用浏览器打印。

### 双语字幕的两个引擎

| 引擎                 | 说明                                                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **默认字幕**（默认） | 走 Google 公共网页翻译接口 `translate.googleapis.com`，免 Key、免下载语言包、即时可用。字幕会逐条**经网络**发送到该接口翻译。 |
| **AI 字幕**          | 使用你配置的模型。为节省额度优先翻译播放位置附近，点「翻译全部」立即整片翻译。                                                |

翻译结果按 `视频 + 语言 + 引擎` 缓存在本机，重开视频直接复用。可在字幕区的翻译设置里关闭自动翻译、切换引擎，或在原文 / 译文 / 双语之间切换。支持 10 种目标语言。

## 模型选择

| 服务商             | 可选模型                           |
| ------------------ | ---------------------------------- |
| OpenAI             | GPT-4.1 mini、GPT-4.1              |
| DeepSeek           | DeepSeek V4 Flash、DeepSeek V4 Pro |
| Claude · Anthropic | Claude Haiku 4.5、Claude Sonnet 5  |

模型目录来自 [OpenAI](https://developers.openai.com/api/docs/models/gpt-4.1-mini)、[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)、[Claude](https://platform.claude.com/docs/en/models/overview) 官方文档（2026-09-07 核对）。扩展只会请求这三家的官方地址，不支持自定义接口地址；旧版手填配置会保留，设置页会提示重新选择服务商和模型。

## 当前功能

| 功能               | 实现方式                                                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 独立学习页         | 点赞旁保留入口；新标签中播放视频和使用学习工具，不挤压原 YouTube 页面                                                        |
| 原生字幕与字幕导入 | 优先读取原生字幕响应，接口不可用时读取 YouTube 转录面板；支持 SRT / VTT / JSON3 / XML                                        |
| 双语字幕           | 随播放自动逐句翻译，视频下方与右侧列表同步双语、当前句高亮；两个引擎、10 种语言、按视频+语言+引擎缓存复用                    |
| 章节               | 优先显示 AI 内容目录，其次 AI 总结章节，都没有时回退到**视频自带章节**，打开即可用；标题栏标明当前来源，并可一键生成 AI 目录 |
| 引导提问           | 看之前先由 AI 依据字幕提出 5~8 个关键问题，按视频回答的先后排序；点时间戳直接跳到对应位置，**答案默认收起**，想核对时再展开  |
| 播放同步           | 当前句高亮、自动滚动、点击句子或引用跳转、手动滚动暂停跟随                                                                   |
| AI 总结            | 处理已载入的全部字幕；长文本分段分析、分层汇总；保留可核对时间点                                                             |
| 自定义 Prompt      | 模板、编辑和本机保存；用于实际 AI 请求及导出文档                                                                             |
| AI 问答            | 依据字幕回答，附有效字幕时间点；当前为独立提问，不携带多轮聊天历史                                                           |
| 导出               | 一键下载 PDF（文字可搜索可复制、时间点可点击回视频）、真实 `.xmind`、Markdown，另可打开排版页打印；均附视频来源与所用 Prompt |
| 任务管理           | 显示进度与已用时间、可主动取消；关闭学习标签时取消请求；原页面切换不会替换学习中的视频                                       |

思维导图不再是单独的标签页，而是导出格式：`.xmind` 的树由总结内容直接推导，根节点是标题，下面是内容概览、每一章及其要点、行动与启发 —— 不看视频也能顺着导图读懂全片。

## 已知范围

- **「默认字幕」会把字幕逐条发送到 Google 的公共网页翻译接口** `translate.googleapis.com/translate_a/single`。该接口是 Google 未公开文档的内部端点，可能随时变更或限流；返回 429 时会提示切换「AI 字幕」。如果不希望字幕出网，请改用「AI 字幕」并自行选择服务商。完整数据说明见 [数据与权限](docs/privacy.md)。
- 代码中另有一条基于 [Chrome 内置 Translator API](https://developer.chrome.com/docs/ai/translator-api) 的本机翻译实现（`src/ui/google-translate.ts`），但当前界面**没有任何入口会走到它**，属于待决策的保留实现。相关自动化测试因此覆盖的是不可达路径。
- **已在视频 `QLLuZbuTIRc` 实站读取 2,354 条字幕**，并验证独立页播放和点击字幕跳转。该会话的字幕接口返回 HTTP 200 空正文，现通过 YouTube 自带转录面板读取。面板读取的覆盖范围仍标记为「未验证」；不能保证所有视频、账户、地区均可读取。失败时可重新读取或导入字幕。
- 学习页保留一套视频下方字幕，初始化及重新开启学习字幕时关闭播放器原生 CC。先检查播放器公布的模块能力，缺少该能力的播放器仍可播放；用户手动打开原生 CC 后可用学习页 CC 开关重新接管。
- 独立学习页是扩展自带页面，不需要部署网站。播放器使用 YouTube 嵌入播放；禁止嵌入的视频会明确提示返回原视频。首次字幕读取依赖原 YouTube 标签，读取成功后本次学习会话可复用字幕。
- 无字幕视频暂未接入音频转写，也未做画面识别。总结依据已载入字幕；导入文件无法自动证明覆盖整段视频，界面会标明覆盖范围未验证。
- OpenAI / DeepSeek 使用 Chat Completions；Claude 使用原生 Messages 接口，并按模型适配参数。账户权限和计费由各服务商决定，长视频会产生多次请求。分段分析单次 45 秒超时，全片汇总 90 秒；限流、超时和格式不符会自动重试，模型返回结构不符时会把出错字段回喂给模型再试。个别片段始终失败会被跳过并在结果上标注覆盖率，不再丢弃整轮工作。
- 已验证真实扩展通过本地 HTTP 测试服务发起请求；没有使用真实密钥验证付费服务及实际总结质量。
- PDF 在本机生成，不经任何服务器。扩展内置一份 [Noto Sans SC](https://github.com/notofonts/noto-cjk)（SIL OFL 1.1，见 `extension/fonts/LICENSE.txt`）子集字体，覆盖 GB2312 全部 6,763 个汉字及常用标点符号；生僻字若不在子集内会被跳过而不是显示豆腐块。字体约 1.5MB，PDF 引擎约 1.3MB，都只在真正导出 PDF 时才加载，不影响平时打开视频。
- XMind 已通过官方开源读取器的独立兼容性检查；尚未在 XMind 桌面版验证布局及编辑保存，导出图片附件也尚未验证。
- 此版本是手动加载的开发版，尚未提交浏览器商店，也未实现登录、订阅、云端同步。

## 权限

| 权限                                  | 用途                                                                                      |
| ------------------------------------- | ----------------------------------------------------------------------------------------- |
| `storage`                             | 保存设置、偏好、翻译与 AI 结果缓存；API Key 默认只存会话存储                              |
| `activeTab`                           | 从当前 YouTube 标签读取视频信息与字幕                                                     |
| `declarativeNetRequestWithHostAccess` | 学习页内嵌播放所需的请求头调整                                                            |
| `host_permissions`                    | `youtube.com`、`m.youtube.com`、`translate.googleapis.com`                                |
| `optional_host_permissions`           | 仅三家 AI 服务商官方域名，以及本地测试用的 `localhost` / `127.0.0.1`；配置 Key 后按需申请 |

扩展不加载任何远程代码（`script-src 'self'`），没有统计 SDK，也没有运营方服务器。

## 开发与测试

推荐 Node.js 24 LTS。在项目根目录执行：

```powershell
npm ci
npm run check
npm run test:e2e
npm run test:ads
```

`check` 包含严格 TypeScript 检查、ESLint、单元测试和生产构建。E2E 使用真实 Chromium 加载生产扩展，需要已安装 Playwright Chromium；不存在时先运行 `npx playwright install chromium`，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器路径。测试中的 YouTube 页面和 AI 响应采用受控样例，不会消耗真实 API 额度。

```powershell
# 单独构建 dist 和 release 压缩包
npm run build

# 独立 XMind 文件兼容性检查（会下载固定版本的公开测试工具）
node --import tsx tests/compatibility/verify-xmind.ts
```

开发时加载 `dist` 文件夹；改动源码后重新构建，在扩展管理页点「重新加载」，关闭旧学习标签并刷新 YouTube。

源码分层、测试边界和数据说明见 [架构说明](docs/architecture.md)、[测试记录](docs/testing.md)、[数据与权限](docs/privacy.md)。
