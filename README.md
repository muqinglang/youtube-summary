# 旁听 Sidenote · YouTube AI 学习插件

基于已确认的深色 UI，开发的 Chrome / Edge Manifest V3 扩展。当前版本 `0.6.0` 使用独立学习页面。默认用 Google 云端翻译随播放自动显示双语字幕（免 Key、免下载）；AI 总结、内容目录、问答及可选的 AI 翻译支持 OpenAI、DeepSeek 和 Claude 的官方接口。

## 安装与开始使用

1. 使用 Chrome / Edge 130 或更新版本，打开扩展管理页：`chrome://extensions` / `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择本项目的 **`dist` 文件夹**。不要选择项目根目录。
3. 打开或刷新 YouTube 视频页，点击视频下方点赞左侧的 **旁听 AI** 按钮，或浏览器工具栏中的旁听图标。扩展会暂停原视频，打开独立学习标签：左侧是居中视频、双语字幕和底部播放控制，标题位于顶部；右侧按「字幕｜章节｜AI 总结｜思维导图｜AI 问答」切换。同一视频再次点击会回到已有学习标签。
4. 等待字幕读取完成，期间保留原 YouTube 标签页。扩展必要时会打开原视频的「显示转录内容」读取字幕。也可导入该视频对应的 SRT / VTT 文件。
5. 选择目标语言即可，字幕载入后会**随播放自动逐句翻译**（Trancy 式双语），无需手动点按钮；视频下方与右侧字幕列表同步显示双语、当前句高亮跟随。默认「自动选择」引擎：没有 AI Key 或模型时使用 **Google · Chrome 内置翻译**（免 Key，一次翻译整片并显示进度）；配置 AI 后使用该模型，且为节省额度优先翻译播放位置附近，点「翻译全部」可立即整片翻译。翻译进度按 视频+语言+引擎 缓存，重开视频复用。可在字幕区关闭「自动翻译」、手动选择 Google / AI、或切换原文 / 译文。首次使用 Google 翻译需下载语言包；浏览器须支持 Translator API（桌面 Chrome 138+），不支持或下载失败会明确提示，并提供仅翻译当前句的 Google 网页入口。
6. 需要 AI 总结或问答时，在顶部「AI 设置」先选择 **服务商 → 模型**，再填写对应 **API Key**。官方服务地址由扩展内置，保存并允许访问该服务后即可测试连接。切换服务商会清除旧密钥。默认不记住密钥，浏览器关闭后清除；勾选记住后存于本机。可在「AI 总结」中保存 Prompt。
7. 使用「导出笔记」下载 XMind / Markdown；PDF 会打开独立排版页，点击打印按钮，在浏览器打印窗口选择「另存为 PDF」。

可分发的开发版压缩包：`release/sidenote-0.6.0.zip`。解压后加载包含 `manifest.json` 的文件夹即可。已加载本项目 `dist` 的用户，在扩展管理页点击「重新加载」，关闭旧学习面板并刷新 YouTube 后即可使用新版。更新源码后先重新构建。

## 模型选择

| 服务商             | 可选模型                           |
| ------------------ | ---------------------------------- |
| OpenAI             | GPT-4.1 mini、GPT-4.1              |
| DeepSeek           | DeepSeek V4 Flash、DeepSeek V4 Pro |
| Claude · Anthropic | Claude Haiku 4.5、Claude Sonnet 5  |

模型目录来自 [OpenAI](https://developers.openai.com/api/docs/models/gpt-4.1-mini)、[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)、[Claude](https://platform.claude.com/docs/en/models/overview) 官方文档（2026-09-07 核对）。旧版手填配置会保留，设置页会提示选择服务商和模型后更新。

## 当前功能

| 功能               | 实现方式                                                                              |
| ------------------ | ------------------------------------------------------------------------------------- |
| 独立学习页         | 点赞旁保留入口；新标签中播放视频和使用学习工具，不挤压原 YouTube 页面                 |
| 原生字幕与字幕导入 | 优先读取原生字幕响应，接口不可用时读取 YouTube 转录面板；支持 SRT / VTT / JSON3 / XML |
| 双语字幕           | 字幕载入后随播放自动逐句翻译（Trancy 式），视频下方与右侧列表同步双语、当前句高亮；AI 翻译优先翻译播放位置附近以省额度，「翻译全部」可整片翻译，翻译进度按视频+语言+引擎缓存复用；10 种目标语言，原文 / 译文 / 双语切换，可关闭自动翻译 |
| 内容目录（章节）   | 「章节」标签是书本式 AI 内容目录：由 AI 总结把全片按内容小结成带时间点的章节，每节列出要点，点击跳转、当前节高亮 |
| 播放同步           | 当前句高亮、自动滚动、点击句子或引用跳转、手动滚动暂停跟随                            |
| AI 总结            | 处理已载入的全部字幕；长文本分段分析、分层汇总；保留可核对时间点                      |
| 自定义 Prompt      | 模板、编辑和本机保存；用于实际 AI 请求及导出文档                                      |
| 思维导图           | 根据总结生成树形结构，支持节点展开、收起和时间点回看                                  |
| AI 问答            | 依据字幕回答，附有效字幕时间点；当前为独立提问，不携带多轮聊天历史                    |
| 导出               | 真实 `.xmind`、Markdown 和浏览器打印 PDF，附视频来源及使用的 Prompt                   |
| 任务管理           | 显示进度、主动取消；关闭学习标签时取消请求；原页面切换不会替换学习中的视频            |

## 已知范围

- Google 翻译使用 [Chrome 官方 Translator API](https://developer.chrome.com/docs/ai/translator-api)，字幕在本机处理，模型和语言包由浏览器下载。功能受浏览器、语言组合、磁盘空间及下载网络影响；不会在失败后悄悄切换到付费 AI。它不是 Google Cloud Translation API，也不调用未经公开支持的网页内部接口。未知字幕语言使用本地 Language Detector，首次下载检测模型后可能需要再次点击翻译。
- 本轮真实 Chrome 151 已确认 API 可用并开始下载组件，但英语中文语言包在五分钟检查窗口内尚未就绪，未获得真实 Google 译文。自动化测试验证路由、逐句显示及取消流程，不能代替模型下载完成后的实际译文验证。
- **已在用户提供的视频 `QLLuZbuTIRc` 实站读取 2,354 条字幕**，并验证独立页播放和点击字幕跳转。该会话的字幕接口返回 HTTP 200 空正文，现通过 YouTube 自带转录面板读取。面板读取的覆盖范围仍标记为「未验证」；不能保证所有视频、账户、地区均可读取。失败时可重新读取或导入字幕。
- 学习页保留一套视频下方字幕，初始化及用户重新开启学习字幕时关闭播放器原生 CC。先检查播放器公布的模块能力，缺少该能力的播放器仍可播放；用户手动打开原生 CC 后可用学习页 CC 开关重新接管。章节来自当前视频元数据，不使用原型的示例章节。
- 独立学习页是扩展自带页面，不需要部署网站。播放器使用 YouTube 嵌入播放；禁止嵌入的视频会明确提示返回原视频。首次字幕读取依赖原 YouTube 标签，读取成功后本次学习会话可复用字幕。
- 无字幕视频暂未接入音频转写，也未做画面识别。总结依据已载入字幕；导入文件无法自动证明覆盖整段视频，界面会标明覆盖范围未验证。
- OpenAI / DeepSeek 使用 Chat Completions；Claude 使用原生 Messages 接口，并按模型适配参数。可选模型见下表，账户权限和计费由各服务商决定。单次网络请求 25 秒超时；超时、额度不足和格式不兼容均显示错误。长视频会产生多次请求。
- 已验证真实扩展通过本地 HTTP 测试服务发起请求；没有使用用户密钥验证付费服务及实际总结质量。
- XMind 已通过官方开源读取器的独立兼容性检查；尚未在 XMind 桌面版验证布局及编辑保存。
- 此版本是本地加载的开发版，尚未提交浏览器商店，也未实现登录、订阅、云端同步。

## 开发与测试

推荐 Node.js 24 LTS。在项目根目录执行：

```powershell
npm ci
npm run check
npm run test:e2e
npm run test:ads
```

`check` 包含严格 TypeScript 检查、ESLint、单元测试和生产构建。E2E 使用真实 Chromium 加载生产扩展，需要已安装 Playwright Chromium；不存在时先运行 `npx playwright install chromium`，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器路径。测试中的 YouTube 页面和 AI 响应采用受控样例，不会消耗真实 API 额度。

```powershell
# 单独构建 dist 和 release 压缩包
npm run build

# 独立 XMind 文件兼容性检查（会下载固定版本的公开测试工具）
node --import tsx tests/compatibility/verify-xmind.ts
```

源码分层、测试边界和数据说明见 [架构说明](docs/architecture.md)、[测试记录](docs/testing.md)、[数据与权限](docs/privacy.md)。
